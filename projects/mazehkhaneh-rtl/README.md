# مزه‌خانه — Arabic Food RTL Website

بازسازی کدنویسی‌شده از ویدیوی مرجع Pinterest با تمرکز روی ساختار تمیز، RTL، ریسپانسیو و بدون وابستگی سنگین.

## Stack
- Semantic HTML5
- Modern CSS (Grid/Flex, RTL, responsive)
- Vanilla JavaScript
- Vazirmatn Persian typography

## اجرا
