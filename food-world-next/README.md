# Eastern Table — Next.js / React / TypeScript

نسخه Next.js پروژه رستوران فارسی و RTL، با الهام از ویدیوی مرجع ارسالی.

## Stack
- Next.js App Router
- React
- TypeScript
- Lucide React
- Responsive CSS
- RTL / Persian typography
- Local SVG assets

## Run locally
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید.

## Production
```bash
npm run build
npm start
```

## Vercel
ریشه پروژه را روی `food-world-next` قرار دهید. Vercel این پروژه را به‌عنوان Next.js تشخیص می‌دهد و نیازی به تنظیمات build سفارشی ندارد.
