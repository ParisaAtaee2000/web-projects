# Eastern Table — نسخه فارسی و RTL

بازطراحی و پیاده‌سازی الهام‌گرفته از ویدیوی مرجع ارسالی.

## Stack
- React + TypeScript
- Vite
- CSS responsive
- RTL / Persian typography
- Lucide icons
- Custom SVG food illustrations (local assets)

## Sections
- Header / navigation
- Hero با کارت‌های غذایی و اسلایدر تعاملی
- نوار متحرک Food World
- Why Choose Us
- دسته‌بندی غذا
- منوی امروز و کارت محصولات
- سفارش آنلاین
- داستان برند
- مهمان‌های ویژه
- Footer

## Run
```bash
npm install
npm run dev
```

این پروژه داخل مخزن `web-projects` در مسیر `food-world-fa` قرار دارد.
