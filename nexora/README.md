# NEXORA

فروشگاه راست‌چین اشتراک‌ها و سرویس‌های دیجیتال، پیاده‌سازی‌شده با React، TypeScript و Vite.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت خروجی نهایی:

```bash
npm run build
```

## ساختار

- `src/App.tsx`: کنار هم قرار دادن بخش‌های صفحهٔ اصلی
- `src/components/`: هدر، فوتر، آیکن‌ها و سکشن‌های صفحه
- `src/data/store.ts`: داده‌های نمونهٔ دسته‌بندی، محصول و مقاله
- `src/styles.css`: توکن‌های بصری، چیدمان و breakpoints واکنش‌گرا
- `public/assets/`: تصاویر صفحهٔ اصلی

اطلاعات فروشگاه در `src/data/store.ts` دادهٔ نمایشی هستند؛ برای اتصال بک‌اند، این بخش و فرم خبرنامه نقطه‌های اصلی اتصال به API هستند.
