# NEXORA

فروشگاه راست‌چین اشتراک‌ها و سرویس‌های دیجیتال، پیاده‌سازی‌شده با React، TypeScript و Vite.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت خروجی نهایی:

```bash
npm run build
```

## ساختار

- `src/App.tsx`: کنار هم قرار دادن بخش‌های صفحهٔ اصلی
- `src/components/`: هدر، فوتر، آیکن‌ها و سکشن‌های صفحه
- `src/pages/`: فروشگاه، جزئیات محصول، سبد، تکمیل سفارش، مجله و صفحات ثابت
- `src/components/CartContext.tsx`: سبد نمایشی سمت مرورگر با ذخیره در `localStorage`
- `src/data/store.ts`: داده‌های نمونهٔ دسته‌بندی، محصول و مقاله
- `src/styles.css`: توکن‌های بصری، چیدمان و breakpoints واکنش‌گرا
- `public/assets/`: تصاویر صفحهٔ اصلی

## مسیرهای فعلی

- `/` خانه
- `/shop` فروشگاه و فیلتر دسته‌بندی، جست‌وجو و مرتب‌سازی
- `/product/:slug` جزئیات محصول
- `/cart` سبد خرید نمایشی
- `/checkout` فرم اولیهٔ ثبت سفارش
- `/journal` فهرست مقاله‌ها و `/journal/:id` متن مقاله
- `/help`، `/about`، `/contact`، `/account` و `/favorites`

اطلاعات فروشگاه در `src/data/store.ts` نمایشی هستند. سبد خرید نیز فعلاً فقط در مرورگر ذخیره می‌شود؛ اتصال API، احراز هویت و درگاه پرداخت باید در مرحلهٔ بک‌اند اضافه شوند.
